# لوحة فرص التوظيف — تحديث يومي تلقائي مجاني

هذه النسخة مصممة للعمل مجانًا على GitHub Pages، مع GitHub Actions لتحديث `jobs.json` يوميًا.

## ماذا يحدث تلقائيًا؟
- الساعة 11:00 صباحًا بتوقيت الرياض، GitHub Actions يشغل `update_jobs.py`.
- السكربت يراجع صفحات الوظائف الرسمية المحددة في الكود.
- يستبعد أي إعلان يحتوي على Saudi National / Saudization / Tamheer ونحوها.
- يحتفظ فقط بمسميات الإدارة العليا المناسبة للطرق والبنية التحتية.
- يحسب درجة تطابق تقريبية ويمنع التكرار حسب رابط الوظيفة.
- يحدث `jobs.json` ثم الصفحة تقرأه تلقائيًا.

## النشر المجاني
1. أنشئ Repository جديدًا في GitHub وارفع محتويات هذا المجلد إلى جذر المستودع.
2. من Settings > Pages اختر Deploy from a branch ثم main / root.
3. من Actions شغّل `Daily jobs update` يدويًا أول مرة للتجربة.
4. بعد ذلك سيعمل يوميًا حسب الجدول.

## ملاحظة مهمة
GitHub يذكر أن scheduled workflows قد تتأخر قليلًا عن وقت cron المحدد، لذلك 11:00 هو وقت الاستهداف وليس ضمانًا بالدقيقة.

## الخصوصية
GitHub Pages موقع ثابت. تسجيل دخول آمن بيوزر/باسورد يحتاج طبقة وصول خارجية (مثل Cloudflare Access) أو Backend. لا تضع كلمات مرور حقيقية داخل JavaScript في الصفحة.
